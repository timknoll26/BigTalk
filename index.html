Spieler

Optional – nur für den Punktestand. Ohne Spieler wird ohne Punkte gespielt.

    Kurzregeln
    1. Das Handy zeigt eine Challenge, z. B. „Wie viele Liegestütze schaffst du?“
    2. Alle überbieten sich lautstark. Wer das Handy hält, tippt jedes neue Gebot mit + ein.
    3. Jedes Gebot setzt den Timer zurück. Bietet niemand mehr, läuft er ab.
    4. Der Höchstbieter muss sofort beweisen, dass er es schafft. Die Gruppe entscheidet.
